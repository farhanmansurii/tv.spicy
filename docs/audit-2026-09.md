## Corrections to earlier findings

Two claims from the audit passes did not survive verification and are recorded here so they are not repeated.

**The 769-1023px navigation dead zone does not exist.** The claim was that `lg:hidden` overrides `md:flex` in that range. `lg:hidden` compiles to `@media (min-width: 64rem)`, so it does not match below 1024px. At 800px only `md:flex` applies, the desktop branch at `components/ui/sidebar.tsx:230` renders, and `toggleSidebar` (`:103`) flips `open`, which drives `state` at `:123`. The panel opens. The real defect is narrower: `aria-expanded={openMobile}` and the open/close `aria-label` at `components/layout/header/header.tsx:209-214` never change when `isMobile` is false, so the hamburger reports the wrong state to assistive tech.

**Reduced motion is not globally disabled.** `hooks/use-reduced-motion.ts`, `lib/motion.ts` and `lib/gsap-accessible.ts` are stubbed out, but nothing imports them. Components use `useReducedMotion` from `framer-motion`, which works. The three stub files are dead code that misleads a reader. The actual gap is four unguarded GSAP files, listed under F-UI-6 below.

## P0

### F-0-1: sync deletes server watch history outside a top-24 cap

`mergeRecentlyWatchedBatch` (`lib/db/recently-watched.ts:127-153`) builds a merged set, then `deleteMany` on every server row absent from it. The merged set passes through `sanitizeContinueWatchingItems` (`lib/continue-watching.ts:158`) with `limit = 24` (`:165`) and filters that drop TV items at `progressPercent >= 95` (`:174-178`). A user with more than 24 history rows loses the excess on every sync. `app/api/sync/route.ts:55-71` runs the merge even when the payload is empty. Nothing is transactional.

### F-0-2: cross-account contamination on shared devices

Persist keys are global: `watchlist-storage` (`store/watchlistStore.ts:349`), `favorites-storage` (`store/favoritesStore.ts:272`), `continue-watching-storage` (`store/recentsStore.ts:395`). Sign-out at `components/auth/auth-button.tsx:197-202` clears the session but not those keys. The next login runs `bootstrapUserData` (`components/auth/auth-sync.tsx:47-63`), which calls `collectLocalData` (`lib/sync/local-to-db.ts:45-75`) and uploads the stores unconditionally. User B absorbs user A's data. The comment at `auth-sync.tsx:14-17` documents the persistence as intended, but does not account for a second account on one browser.

### F-0-3: a live TMDB key is in git history

`git log --all --diff-filter=A -- .env` returns `1d5e40e` and `2d57eac`. `git show 1d5e40e:.env` still yields the key. It was removed in `c799866`, which does not remove it from history. Rotate the key. Scrub history if the repository is public.

## P2 - gaps

**Dead code: 8,420 of 27,541 lines (31%) are unreachable from `app/`.** 41 of 56 `components/ui/*` files including `command-palette.tsx` (1,452 lines), `command.tsx`, `dialog.tsx`, `toaster.tsx`. **Never-imported dependencies:** `zod`, `lodash`, `bcryptjs`, `idb`, `@vercel/postgres`, `@studio-freight/react-lenis`, `@imbios/next-pwa`, `embla-carousel`, `embla-carousel-autoplay`, `react-intersection-observer-hook`, `tailwind-variants`, `@emotion/memoize`, `playwright`. Reachable only through dead code: `axios`, `react-hook-form`, `@hookform/resolvers`, all five `@oplayer/*` packages, and 13 `@radix-ui/*` packages.

**Duplication:** three icon libraries (`@phosphor-icons/react` 28 files, `lucide-react` 16, `@radix-ui/react-icons` one import in a dead file); two toast systems; two mobile-breakpoint sources (`store/mediaQueryStore.ts:15,21` at 768px versus Tailwind `lg` at `components/layout/header/header.tsx:65`); three top-offset recipes for the same fixed header.

**Broken plumbing:** no `.env.example` although `README.md:42` tells you to copy one. PWA unlinked (`public/manifest.json` is never referenced, `@imbios/next-pwa` unused, manifest contains `"scope": "000026"` and `"dir": "rtl"`). `app/robots.ts` disallows all crawling while `app/sitemap.ts` publishes URLs and `app/layout.tsx:52-61` sets `index: false`. `tailwind.config.ts` and the empty `tailwind.config.js` are never loaded because `app/globals.css` has no `@config` directive and Tailwind v4 does not auto-load JS config. `tailwind-merge` is 1.14.0 against Tailwind 4.1.6 while current is 3.7.0, so `cn()` (342 call sites) can fail to merge conflicting classes. `DESIGN.md:438` describes a global reduced-motion rule that is scoped to `.liquid-glass-surface`, and `DESIGN.md:537-546` lists slugs as missing that exist in `lib/browse-categories.ts:31,59`.
